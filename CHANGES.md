# What changed from the original code

## Bugs fixed

| #   | Where                | Problem                                                                                                                                                                                      | Fix                                                                         |
| --- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 1   | `ApiError`           | Constructor was `(status, data, errors, message)` but called as `(status, message)`, so **every error message was lost** and replaced by a default                                           | Signature is now `(statusCode, message, errors, code)`                      |
| 2   | login / middleware   | Cookies set as `accessToke`/`refreshToke` but read as `accessToken`/`refreshToken` → cookie auth never worked                                                                                | Single source of truth in `AUTH_COOKIE` constants                           |
| 3   | `getUser`            | `res.stack(200)` → crash                                                                                                                                                                     | Fixed (`GET /users/me`)                                                     |
| 4   | forgot password      | `generateTemporaryToken()` not awaited → token was `undefined`; field names (`forgotPasswordToke` vs schema `forgetPosswordExpiry`) didn't match the schema, so values were silently dropped | Consistent fields, sync method, tested end-to-end                           |
| 5   | email links          | Link pointed to `/api/v1/users/verify-email/…` but route was `/auth/verity-email/…` (typo); resend link missed a `/`                                                                         | Correct `GET /auth/verify-email/:token`                                     |
| 6   | `refreshAccessToken` | `throw new ApiResponse(...)` (not an Error), swallowed its own errors, set non-existent `user.accessToken`, odd status codes (404/402/407/489)                                               | Rewritten with rotation + proper 401s                                       |
| 7   | login                | Wrong password → 404; "user doesn't exist" message leaked which emails are registered                                                                                                        | 401 + identical message, timing-equalized                                   |
| 8   | forgot password      | Revealed whether the email exists                                                                                                                                                            | Always 200, same message                                                    |
| 9   | no error middleware  | Thrown `ApiError`s would return Express's HTML error page                                                                                                                                    | Global JSON error handler (Mongoose, JWT, body-parser, duplicate-key aware) |
| 10  | `index.js`           | `dotenv.config()` ran after `import app` (imports are hoisted) → `CORS_ORIGIN` was never applied                                                                                             | `config/env.js` loads dotenv first and validates everything                 |
| 11  | CORS                 | `origin: "*"` + `credentials: true` is rejected by browsers                                                                                                                                  | Explicit allow-list; `*` rejected at startup with a clear message           |
| 12  | validators           | `password` was `.trim()`-ed (altered the user's password); `fullName` vs `fullname` mismatch; NoSQL operator objects accepted                                                                | No trim on passwords, unified `fullName`, `isString()` checks               |
| 13  | schema               | Duplicate index on `username` (`unique` + `index`), `password` selectable by default                                                                                                         | Cleaned; `select:false` on password and tokens                              |
| 14  | mail                 | Hardcoded personal sender, SMTP transport created per email, failures swallowed in a confusing way, typos                                                                                    | Reusable transporter, `MAIL_FROM`, console fallback in dev, never throws    |
| 15  | register             | `role` destructured but unused; returned 200; sent mail errors undetected                                                                                                                    | 201, role ignored (no mass assignment)                                      |
| 16  | misc                 | Unused imports (`send`, `SendmailTransport`), deprecated `crypto` npm package, junk `public/images/this.js`, wrong `main`, Express 5 `req.body` undefined when empty                         | Removed / handled                                                           |
| 17  | logout               | Stored the string `"empty"` as refresh token; only one token per user                                                                                                                        | Session documents                                                           |
| 18  | Found while testing  | Two simultaneous refreshes (two tabs) revoked the whole session                                                                                                                              | Grace window on reuse detection                                             |

## Features added

Sessions per device · refresh-token rotation + reuse detection · logout (this device) · **logout all devices** (+ keep current) · list/revoke sessions · session cap per user · **rate limiting** (6 limiters) · **account lockout** · public resend-verification · password-changed emails · change/reset password revoke sessions · login by email or username · profile update · account deletion · **RBAC** (`authorizeRoles`) · admin: list/search/paginate users, change role, deactivate · seed-admin script · helmet, NoSQL sanitizer, body limits · env validation · graceful shutdown · healthcheck with DB state · error codes · `.env.example` · 42 integration tests.

## Renamed / moved routes

`/auth/verity-email/:t` → `GET /auth/verify-email/:t` · `/auth/forgor-password` → `/auth/forgot-password` · `POST /auth/current-user` → `GET /users/me` · `resend-email-verification` is now public (body `{email}`).
Validation error shape: `errors: [{ field, message }]`.
